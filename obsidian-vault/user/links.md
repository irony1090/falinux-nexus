### 구현 기준 시안(WPLq) 사용법
- **화면**: PC·폰 두 프레임. 기기 선택·숫자 입력·오른쪽 아래 점 드래그로 크기 변경. 상단에 2분할 기준(728/560), 예시 배치, 전체보기 축소 비율.
- **예시 배치**: 처음 / 순서 예시 / 중첩 폴더 / 크기 섞기 / **프로세스 많이**(기본, 터미널 9개) / 중간·마지막 빈 칼럼.
- **타일 조작**: 폴더 타일의 실행·새 타일, 헤더 크기 버튼(0.5/1.0), kill, 닫기. 동작하면 두 화면이 같이 재배치되고 자리 바뀐 타일에 점선 + `G1→G2` 표시.
- **전체보기**: 각 화면 Grid 하단 정보 줄 오른쪽 끝의 파란 버튼. 타일 누르면 그 Grid로, Esc·돌아가기면 원래 위치로. 처음엔 PC만 전체보기 상태.
- **가상 키보드**: 폰 화면 터미널 출력 부분을 누르거나 화면 위 `가상 키보드` 버튼. 툴바에서 판정 기준(보이는 영역 = 재배치 문제 재현) / 입력 모드 켬·끔 / 터미널 크기(유지+스크롤 · 맞춤) 비교. 열고 닫을 때 재배치 여부는 "변경 기록" 카드에 남음.
- **헤더**: G탭(폭 모자라면 `G1 … c-1 c c+1 … 끝`), 칼럼 위치(`칼럼 6-7/7`), ‹ › 칼럼 이동.
- 노드·터미널 출력은 전부 예시 데이터.

### 버전 이력 (WPLq)
| 버전 | 바뀐 것 |
|---|---|
| v1 | 전체보기 첫 시안 (여러 줄 / 가로 한 줄 토글) |
| v2 | 긴 축 한 줄 + 짧은 축 가운데로 확정, 토글 제거 |
| v3 | 오른쪽 아래 큰 떠 있는 버튼 (타일 가림) |
| v4 | Grid 하단 정보 줄 높이의 작은 버튼, 그 줄 오른쪽 끝에 고정 |
| v5~v7 | 스크롤바 대응: 항상 표시 → 숨김 → **auto + 두께만큼 버튼 이동**(최종) |
| v8 | G탭 줄임 표시 추가 |
| v9 | 끝 페이지 잘림 버그 수정, 칼럼 위치 범위 표시, 동점이면 뒤쪽 Grid가 현재 |
| v10 | 가상 키보드 토글(폰 터미널 탭 또는 버튼) + 비교 스위치 3개(판정 기준 / 입력 모드 / 터미널 크기), 보조 키 줄, 화면 위 막대가 두 화면을 겹치게 만들던 문제 수정 |
