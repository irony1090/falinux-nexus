## 확정 (사용자, 2026-10-29)
| 항목 | 결정 |
|---|---|
| 순서 구조 | **부모를 순서에서 떼어 냄.** 화면 순서 = `order` 배열 그대로. 끌어서 옮기면 목록 어디로든(루트만 맨 앞 고정) |
| 새 타일 자리 | 실행·열기로 생긴 타일 = **만든 타일 바로 뒤, 최신이 앞**(A에서 sup1, sup2 실행 → `A / sup2 / sup1`) |
| 연 곳(`parent`) | 끌어서 옮겨도 안 바뀜. 쓰는 곳 = 보드로 분리 · 터미널 `[3]`(실행한 타일 위치) · 폴더 "연 곳" 이름(둘 다 유지) |
| 보드로 분리 | 그 폴더가 연 타일 전부(깊은 자식까지, 연 곳 사슬). 새 보드 순서 = 옛 보드에서의 상대 순서 |
| 폴더 닫기 | 그 폴더가 연 타일들의 연 곳 = 닫힌 폴더의 연 곳으로 올림. 화면 순서는 닫힌 타일만 빠짐. `adopted` 폐기 |
| 자식 가능 | 폴더 타일 + 장비 타일(능력-2(자식 가능)) — "디렉토리 타일" |
| 터치 제스처 | 두 손가락 펼치기 = 컨트롤 패널(두 손가락 가운데). 빈 곳 길게 누르기(해석-1: 머리 줄 빈 곳 + 경로 줄·목록 빈 곳) = 타일 옮기기. 목록 칸 길게 = 체크(그대로), 버튼·아이콘·라벨 = 각자 동작 |
| 이미지 보기 타일 | 몸통 안 펼치기 = 이미지 확대(그대로), 그 타일은 머리 줄에서 펼칠 때만 패널 |
| 마우스 | 머리 줄 빈 곳을 누른 채 끌면 바로 옮기기(길게 누를 필요 없음) |
| node 칸 터치 | 칸끌기-A(누른 채 움직임): 길게 눌러 움직이지 않으면 체크, 누른 채 움직이면 끌기 |
| node 순서 권한 | 편집 권한자만(공유 폴더는 보는 사람 모두에게 같이 바뀜) |
| 범위 | node 보드 + 폴더 타일 node 칸. **회원 관리 판 제외**(→ `BACKLOG.md`). 장비 타일 목록은 worker 파일이라 대상 아님 |
| 코드 정리 | 트리 쪽을 손대는 김에 같이 다듬음(아래 "정리 대상") |
| `kids` | **없앰**(필요 없으면 빼기, 사용자). 문서 = `parent`(연 곳) + `order` |
| 전체보기 | 전체보기에서도 끌기 + **보드 간 이동**(다른 보드 줄로 끌어 놓기) |
| 연 곳 없는 타일 | 연곳-B(루트 바로 뒤): 공유로 받은 타일·고아 안전망 터미널·연 곳이 닫힌 실행 = 루트 바로 뒤(최신이 앞과 같은 규칙). 기각 = 연곳-A(맨 뒤) |
| 보드-1 범위(보드Q1~Q5) | 보드Q1(끌 수 있는 타일) = 전체보기의 **모든 보드 줄** / 보드Q2(묶음 미리보기) = 다른 보드 줄 위에서 묶음 전체가 옮겨 보임 / 보드Q3(빈 곳에 놓기) = 맨 뒤 / 보드Q4(같은 보드 안 순서) = 하나만 / 보드Q5(묶음 모양) = 끄는 타일만 빈 자리, 나머지는 내용 그대로 + **실선 파랑 테두리·옅은 바탕**(10-29 사용자 요청으로 고침) / 보드Q6(묶음 표시 때) = 다른 보드 줄 위에서만(묶음 이동은 보드 간 이동뿐) — 작은 표시에도 같이 가는 타일 이름(3개 + 외 N개) / 보드Q7(평소 모드) = 표시 없음 |
| 칸Q1(넣기 vs 순서) | **비켜 가기 + 머무르기**: 칸은 타일처럼 비켜 가며 미리보기, 폴더 칸 위에 잠깐(약 0.6초) 머물면 "그 폴더 안으로 넣기"로 바뀜. 기각 = 가운데 넣기·사이 순서(세로 선 표시), 비켜 가기 + 보조 키 넣기 |
| 칸Q2(저장 방식) | **X(들)를 Y 뒤로**: 끈 칸 + 놓은 자리 앞 칸만 보냄, 서버가 안 보이는(차단) 형제까지 다시 번호. 기각 = 보이는 순서 배열 통째로 |
| 칸Q3(루트 목록) | **내 루트끼리만**: 공유받은 루트는 못 끌고 늘 내 루트 뒤 고정(마이그레이션 없음). 기각 = 받는 사람별 순서 저장 |
| 칸Q4(Ctrl 복사) | **넣기에만**(폴더 칸 머무르기·다른 폴더 타일): Ctrl = 복사. 같은 목록 안 순서 바꾸기는 Ctrl 무시(사본 안 만듦). 기각 = Ctrl이면 사본을 Y 뒤에 |
| 칸Q5(애니메이션) | 제안 표대로 바로 구현(모형 없이, 10-29): 끌기 = 작은 표시 + 빈 자리 · 칸 비켜 가기 · 폴더 칸 머무는 0.6초 테두리 차오름 · 넣기 모드 = 빈 자리 원위치 + 폴더 칸 강조 + 표시 글자 "→ 폴더 이름" · 놓기(순서) = 빈 자리로 들어감 · 놓기(넣기) = 끈 칸 줄어들며 사라짐 + 폴더 칸 젤리 |
| 묶음 규칙 = 가(같은 보드 안끼리 통일) | 같은 보드 안 끌기 = 그 타일 하나(연 터미널 안 따라옴), 보드가 바뀌면 = 연 타일까지 묶음째(연 관계 `[3]`·바인딩·연 곳 표시 유지). 기각 = 나(전부 하나만, 연 관계 끊김) |
- 기각(같은 날): 부모-1A(폴더 위 = 자식)·뒤-1(B 묶음 다음) 같은 "놓은 구역으로 부모 정하기" — 규칙이 복잡해서 사용자가 부모 없는 순서 안을 냄

## 정리 대상 (구조-1~3과 같이)
- 서버 `parent.Kids = append` 6곳 → `doc.insertAfter(openerID, tile)` 하나(연 곳이 없거나 닫혔으면 루트)
- `kids` 필드 없앰(확정 10-29). 없애면 parent↔kids 일치 검사·kids 갱신 코드가 통째로 사라짐. 하위가 필요한 곳(분리·보기 타일 중복)은 parent로 구함
- 옛 문서(kids만, order 없음) = 읽을 때 옛 `flatten` 규칙으로 order를 한 번 만들고 저장. 배포 = 프론트·supervisor 같이, 열려 있던 옛 탭은 새로고침
- `adopted`·`OrderedTile.depth` 삭제(프론트 5곳·서버 4곳)
