## 규칙
알약 모양(양끝 반원) 버튼·라벨이 **부모 상자의 벽에 닿으면, 닿은 끝은 반원을 버리고 부모 모양을 따른다.** 벽이 곧으면 곧게, 부모 모서리에 걸리면 부모의 곡선대로. 닿지 않은 안쪽 끝은 반원 그대로.

| 용어 | 뜻 |
|---|---|
| **찰떡 규칙** | 위 규칙의 이름(2026-10-25 사용자 확정, "찰떡같이 붙는다" + 찰떡을 벽에 붙이면 닿은 면만 눌림) |
| **찰떡 알약** | 이 규칙을 따르는 요소(버튼·라벨·끝 블록) |

| 면 | 모양 |
|---|---|
| 어디에도 안 닿음 | 양끝 반원 알약(반지름 = 높이의 절반, `999px`). 진짜 타원 아님 |
| 부모 왼쪽·오른쪽 벽에 닿는 끝 | 둥글기 0 → 부모 벽과 같은 직선 |
| 부모 모서리에 걸친 끝 | 둥글기 0 + 부모가 `border-radius` + `overflow: hidden`으로 잘라 부모 곡선이 됨 |
| 안쪽 끝 | 반원 |
| 위·아래 면 | 알약은 원래 곧으므로 바꿀 것 없음(머리 줄은 "윗변 제외, 왼쪽·오른쪽 끝만"으로 정리했던 것과 같은 말) |

## 만드는 법
```css
/* the end touching the wall: radius 0 */
.right-edge { border-radius: 999px 0 0 999px; }
.left-edge  { border-radius: 0 999px 999px 0; }
/* corner curve comes from the parent */
.parent { border-radius: 10px; overflow: hidden; }
```
- 알약 쪽에서 부모 곡선을 흉내 내지 않는다(부모 둥글기가 바뀌어도 알약은 그대로 맞게)
- 부모 쪽 모양(타일 6px 모서리·active 외곽선·공유선 간격)은 건드리지 않는다. 바뀌는 건 알약만
- **부모가 눈에 안 보일 때**(배경·테두리 없는 자리 상자, 예: 찰떡-1(푸터) 2026-10-25): 잘라 줄 부모가 없으니 알약이 자기 `border-radius`로 부모 모양을 그린다(벽 쪽 모서리 = 부모 곡선 값, 예 `0 999px 999px 12px`). `overflow: hidden`으로 자르면 알약 테두리가 곡선에서 끊긴다

## 새 요소를 만들 때
1. 기본은 양끝 반원 알약
2. 부모 왼쪽·오른쪽 벽에 닿는 끝이 있으면 그 끝만 둥글기 0
3. 부모 모서리에 걸치면 부모에 `overflow: hidden`이 있는지 확인(없으면 부모에 넣는다, 알약에서 곡선 흉내 금지)
4. 부모 쪽 모양은 건드리지 않음
5. 다른 프로젝트: 색·크기는 그 프로젝트 규칙을 따르고, 이 모양 규칙만 가져간다

## 시안에서 정리한 규칙 (2026-11-02, updater 시안에서 사용자 지적으로 확정)
| 상황 | 규칙 |
|---|---|
| **묶음은 쪼개지 않는다** | `열기`·`uses` 같은 줄은 낱개 알약 여러 개가 아니라 `.ct-grp` 한 묶음(칸마다 바탕, 칸 사이 1px). 줄바꿈하려고 낱개로 쪼개는 것은 틀림 |
| **오른쪽 정렬 묶음** | 타일 몸통 안에서 오른쪽에 붙는 묶음(`열기`·`uses`·범위 탭·deploy/rollback)은 **타일 벽까지 붙이고**(몸통 패딩만큼 음수 마진) 닿은 끝은 곧게, 안쪽 끝은 반원 |
| **리스트 머리 줄** | 왼쪽 묶음은 왼쪽 벽·머리 줄 높이 꽉·닿은 끝 곧게, 오른쪽 버튼은 오른쪽 벽 |
| **리스트 행의 상태 라벨** | 행 오른쪽 벽에 붙이고 닿은 끝 곧게(벽 쪽 테두리 없음), 글자 위치는 그대로(패딩으로 보정) |
| **라벨-내용 행** | 라벨은 왼쪽, 내용은 오른쪽 정렬(`.fields`). 값이 길면 줄바꿈 |
| **한 줄에 안 들어갈 때 (안 C 한 세트)** | 줄이 바뀌어도 한 묶음. **첫 줄의 왼쪽 끝만 반원**, 아래 줄은 모서리 없음(옆에 이어지는 칸이 있는 것처럼), 모든 줄이 오른쪽 벽에 붙어 곧음, 줄·칸 사이 1px. CSS `flex-wrap` + `justify-content: flex-end`. 비교용으로 안 A(가로 스크롤)·안 B(줄마다 따로 묶음)를 봤으나 안 C 채택 |
| **타일 아래 줄 넘침** (2026-11-02 밤) | 안내 글이 **혼자 한 줄이면 줄바꿈**(두 줄-1), **버튼 옆이면 `...`로 줄이고** 잘렸을 때만 툴팁(마우스 올리기 / 터치 누르기, 바깥 누르면 닫힘) = `MbNote`. 안내 글 최소 60px + 버튼이 안 들어가면 **안내 글이 한 줄을 따로 차지**(배치-2)하고 버튼은 다음 줄, 그래도 넘치면 버튼이 안 C 한 세트로 줄바꿈. 공용 `.mb-foot`(`styles/member.scss`) 한 곳, 회원 관리 타일도 같이 |
| **벽에 붙은 입력칸** (2026-11-02 밤) | 타일 오른쪽 벽에 바로 붙은 `Ct*` 칸(`wall="r"`)은 **벽 쪽 선 없음**(타일 테두리와 두 줄로 겹침, 상태 라벨과 같은 규칙). `ct-field.scss` 한 곳, 대상 = `.upd-fields`·`.mb-fields--wall`의 직접 자식. 옆 칸·버튼에 붙은 `wall`(주소 변경 창 `방식`, 관리 `API 키`)은 선 유지 — 새 상자에 벽 붙은 칸을 두면 선택자에 추가 |
