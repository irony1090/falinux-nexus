## 출발
- 사용자: "터치 스크롤 양 늘리기와 ctrl+alt에 전체보기 버튼과 포커스된 타일의 크기 조절 팝업 띄우기 추가" + "조절 팝업은 우선 크기 조절 버튼 아이콘으로 두고 누르는 것으로"
- 처음에 "ctrl+alt"를 모바일 특수 키 줄(`TerminalKeyBar`)로 잘못 읽음 -> 사용자 정정: **PC에서 Ctrl+Alt를 누르는 동안 커서 위치에 뜨는 페이지 표시 팝업(`PagerPopup.vue`)**, 포커스된 타일 = **active 타일(파란 테두리)**
