## 2026-08-07 — node 카탈로그 UI 컨셉 설계 (코드 없음, 순수 논의)
- 사용자가 "core는 얼추 됐는데 UI 컨셉을 어디서부터 잡을지 모르겠다"로 시작한 브레인스토밍. 이미 확정된 데이터 모델(`REF-node-label.md`의 folder=디바이스 컨테이너/script=실행리프, position_x/y=캔버스 절대배치 vs ord=그리드순서 분리)이 사실상 메타포를 가리키고 있어 그걸 그대로 화면으로 옮기는 방향으로 수렴.
- **확정**: 홈=배치도(캔버스, position_x/y가 실제 랙/사무실 물리배치를 반영) + 트리는 보조내비(breadcrumb=위로 되짚기 / 트리=옆 가지로 점프+검색, 역할 분리). PC=캔버스 유지+모서리 리스트·트리 오버레이 버튼토글(동시표시) / 모바일=`[지도|리스트]` 세그먼트 토글(배타적 전환, %좌표라도 절대간격은 화면폭에 비례해 줄어들어 필요). 트리 재배치 드래그 지원(다른 부모로 폴더/스크립트 이동) — 부수효과로 device_key 상속이 안 보이게 바뀌는 문제(확인 UI 권장, 미확정)와 좌표 없음 문제(이동 노드는 position_x/y=NULL로 두고 ord 그리드 폴백 재사용) 발견.
- **미확정으로 이월**: 모바일 트리 화면 형태(전체화면 검색시트 제안했으나 미확인).
