## 이 파트에만 해당하는 결정
- 종료: 첫 요청 = SIGTERM("종료 요청됨"). 그 뒤 ① 조작(20) 이상 계정의 보드에 그 터미널 타일이 하나도 없거나(보기(10) 계정 타일은 안 셈) ② "종료 요청됨"에서 다시 종료하면 SIGKILL → `REF-process-kill.md` "확정"
- 크기 넘김 대기 = 15초 별도 상수, 탭 id 보관 `tabGrace`는 60초 유지(K3(여유 시간)) / 같은 계정끼리 + 스크립트 소유 계정은 다른 계정에게서도 가져옴(K4(소유 계정 우선)) → `REF-size-take.md`
- xterm 질의(커서 위치 `ESC[6n`·DECRQM·DECRQSS 등)에는 크기 소유 탭만 응답, 나머지 탭은 parser 훅으로 처리 건너뜀 → `REF-term-query.md`
