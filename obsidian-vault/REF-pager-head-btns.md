## 구현
| 이름 | 파일 | 내용 |
|---|---|---|
| 패널-1(창 버튼 등록) | `node/store/tileHeadActs.store.ts`(새) · `TileFrame.vue` | `TileFrame`이 `watchEffect`로 `{minimize?, sizable, close?, closeTitle, closeDisabled}`를 타일 id로 등록(머리 줄과 같은 조건, 동작 = 같은 emit), 언마운트 때 지움. 관리 타일은 등록 없이 `useMemberBoard().close` 직접 |
| 패널-2(묶음) | `PagerPopup.vue` · `MemberPagerPopup.vue` | `#start` = 창 버튼(`.hb`, 오른쪽 1px 선). 크기는 옛 동작 그대로(버튼 가운데 카드) |
| 패널-3(위치 글자) | `GridPager.vue` | prop `count`(기본 true), 패널만 `:count="false"`. 끄면 도트 자리 계산에서도 글자 폭을 안 뺌 |
| 패널-5(도트 최소 폭) | `GridPager.vue` · `MemberDots.vue` | prop `minDots`(기본 0) -> `.bar` `min-width` + 가운데 정렬, 두 패널만 `:min-dots="3"`. `MemberDots .row`는 `flex: none`(막대가 flex가 되며 줄어들지 않게) |

- 등록 해제 = 자기가 등록한 것일 때만(`clearTileHeadActs(id, mine)`). 같은 타일 id의 새 `TileFrame`이 먼저 등록하고 옛 것이 나중에 언마운트되는 경우를 막는 방어 코드 — **이 경우가 실제로 생기는지는 재현 못 함**(Grid 이동·닫기 반복에서 옛 코드도 정상)
- 함정: `GridPager`는 `#start` 폭을 `useResizeCallback`(요소가 생길 때만 등록)으로 잼 -> 슬롯을 `v-if`로 없애면 옛 폭이 남음. 슬롯은 늘 두고 안쪽 버튼만 `v-if`(비면 폭 0)
